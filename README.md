# 3. INPUT REQUIREMENTS

## 3.1 Mandatory Input

### SRT File

SRT ফাইল বাধ্যতামূলক।

এটি ভিডিওর প্রধান Timeline এবং Timing Reference হিসেবে কাজ করবে।

SRT থেকে বের করবে:

- প্রতিটি Subtitle Cue-এর Start Time
- প্রতিটি Subtitle Cue-এর End Time
- প্রতিটি Cue-এর Text
- বাক্যের গঠন
- গুরুত্বপূর্ণ Keyword
- ব্যক্তি ও স্থানের নাম
- সংখ্যা ও পরিমাণ
- তারিখ ও সাল
- Geographic Entity
- Storytelling-এর গুরুত্বপূর্ণ মুহূর্ত
- Scene Transition Point
- Visual Emphasis Point

**গুরুত্বপূর্ণ:** SRT কেবল Timing ও Content Analysis-এর জন্য। SRT-এর বাক্য বা লাইন ভিডিওতে Subtitle হিসেবে দেখানো যাবে না।

| ইনপুট | ব্যবহার |
|---|---|
| Voiceover Audio | Narration ও Visual Sync |
| Sound Effects | Motion Graphics ও Scene Sound |
| Background Music | Background Atmosphere |
| Person Images | ব্যক্তির পরিচিতি |
| Place Images | স্থান ও স্থাপনার পরিচিতি |

নিজে উপযুক্ত সিদ্ধান্ত নিয়ে কাজ চালিয়ে যাবে।

## 3.3 Voiceover Optional Policy

Voiceover বাধ্যতামূলক নয়।

দুটি Workflow থাকবে:

**Workflow A: SRT + Voiceover**

- SRT হবে Timing Reference।
- Voiceover হবে Narration Audio।
- SRT ও Voiceover-এর Timing মিলিয়ে কাজ করবে।
- গুরুত্বপূর্ণ শব্দ ও বাক্যের সঙ্গে Visual Animation Synchronize করবে।
- Audio এবং Visual-এর মধ্যে প্রয়োজনীয় সামঞ্জস্য রাখবে।

**Workflow B: শুধু SRT**

- Voiceover ছাড়াই ভিডিও তৈরি করবে।
- SRT-এর Start ও End Time অনুসরণ করে Scene তৈরি করবে।
- ভিডিওতে কোনো Narration Audio থাকবে না।
- Visual Storytelling, Map Animation, Keyword Graphics ও Motion Graphics দিয়ে বিষয়টি বোঝাবে।
- প্রয়োজন হলে ব্যবহারকারীর দেওয়া Sound Effects বা Background Music ব্যবহার করবে।
- সেগুলো না থাকলে ভিডিও নীরব থাকবে।

শুধু SRT থাকলে Voiceover তৈরি করা, TTS ব্যবহার করা বা AI Voice যুক্ত করা যাবে না, যদি না ব্যবহারকারী স্পষ্টভাবে নির্দেশ দেন।

## 3.4 SRT Timing Accuracy

Standard SRT সাধারণত বাক্য বা Phrase-এর Timing দেয়; প্রতিটি শব্দের আলাদা Timing সবসময় থাকে না।

তাই:

1. SRT-তে Word-Level Timing থাকলে সেটি সরাসরি ব্যবহার করবে।
2. শুধু Sentence-Level Timing থাকলে বাক্যের ভেতরে শব্দের অবস্থান বিশ্লেষণ করে প্রয়োজনীয় Keyword-এর আনুমানিক Timing নির্ধারণ করবে।
3. আনুমানিক Word Timing-কে প্রকৃত Word-Level Timing হিসেবে দাবি করবে না।
4. গুরুত্বপূর্ণ Visual Event-এর Timing Storyboard-এ প্রয়োজন হলে Approximate হিসেবে চিহ্নিত করবে।
5. একই বাক্যে একাধিক গুরুত্বপূর্ণ তথ্য থাকলে সেগুলোকে যৌক্তিকভাবে আলাদা Visual Event-এ ভাগ করবে।
6. কোনো Cue-এর Timing Overlap, Missing Timestamp বা Invalid Format থাকলে আগে সেটি শনাক্ত করবে।

# 4. CORE CREATIVE PRINCIPLES

প্রতিটি ভিডিওতে নিচের নিয়মগুলো অনুসরণ করবে।

1. যে তথ্য বলা হচ্ছে বা SRT-তে প্রকাশ করা হচ্ছে, দৃশ্যে ঠিক সেটিই দেখাবে।
2. শুধু সাজানোর জন্য অপ্রাসঙ্গিক Map, Icon বা Animation ব্যবহার করবে না।
3. Map হবে ভিডিওর প্রধান Visual Element।
4. Map Camera কখনো অপ্রয়োজনীয়ভাবে স্থির থাকবে না।
5. Subtitle বা Caption হিসেবে সম্পূর্ণ বাক্য দেখানো যাবে না।
6. গুরুত্বপূর্ণ Keyword, Number, Date, Place Name ও প্রয়োজনীয় Label দেখানো যাবে।
7. প্রতিটি Visual Element প্রয়োজন অনুযায়ী Animated হবে।
8. কোনো বড় Text বা গুরুত্বপূর্ণ Object হঠাৎ Screen-এ উপস্থিত হবে না।
9. Animation-এর Entry ও Exit উভয়ই পরিকল্পিত হতে হবে।
10. একসঙ্গে সর্বোচ্চ তিনটি নতুন Visual Element প্রবেশ করানোর চেষ্টা করবে।
11. গুরুত্বপূর্ণ তথ্যকে দৃশ্যমানভাবে Highlight করবে।
12. একই তথ্য অপ্রয়োজনীয়ভাবে একাধিক Graphic দিয়ে দেখাবে না।
13. Visual Hierarchy বজায় রাখবে।
14. ম্যাপের মূল বিষয়কে Card, Icon বা Text দিয়ে ঢেকে ফেলবে না।
15. প্রতিটি Scene-এর নিজস্ব Visual Purpose থাকতে হবে।
16. Camera Movement ও Animation-এর গতি Storytelling-এর সঙ্গে সামঞ্জস্যপূর্ণ হবে।
17. একই ভিডিওতে Design Language, Color Meaning ও Typography ধারাবাহিক থাকবে।
18. প্রতিটি Scene দর্শকের বোঝার সুবিধা বাড়াবে।
19. Visual Effects কখনো তথ্যের নির্ভুলতার বিকল্প হবে না।
20. অতিরিক্ত Animation দিয়ে ভিডিওকে অপ্রয়োজনীয়ভাবে ভারী করবে না।

# 5. WORKFLOW & PRODUCTION PIPELINE

কাজ নিচের ক্রমে সম্পন্ন করবে।

## STEP 1: Input Analysis

প্রথমে SRT এবং পাওয়া Optional Assets পরীক্ষা করবে।

বিশ্লেষণ করবে:

- ভিডিওর মূল বিষয়
- ভিডিওর সম্ভাব্য Duration
- বাক্য ও Cue-এর সংখ্যা
- প্রধান Storyline
- গুরুত্বপূর্ণ ব্যক্তি
- গুরুত্বপূর্ণ স্থান
- দেশ ও অঞ্চল
- তারিখ ও সাল
- গুরুত্বপূর্ণ সংখ্যা
- তুলনামূলক তথ্য
- Geographic Movement
- সম্ভাব্য Map Animation
- প্রয়োজনীয় Visual Effects
- Scene Transition

Voiceover থাকলে Audio Duration ও SRT Timing মিলিয়ে দেখবে।

## STEP 2: Story Structure

SRT-এর ভিত্তিতে ভিডিওকে কয়েকটি Logical Scene-এ ভাগ করবে।

প্রতিটি Scene-এর থাকবে:

- Scene ID
- Start Time
- End Time
- Narrative Context
- Main Visual
- Geographic Focus
- Camera Movement
- Highlight Level
- Keyword
- Graphics
- Animation
- Transition

একটি Scene-এ একাধিক তথ্য থাকলে প্রয়োজন অনুযায়ী Sub-scene তৈরি করবে।

## STEP 3: Storyboard

কোড লেখা শুরু করার আগে একটি সংক্ষিপ্ত Storyboard তৈরি করবে।

| Time | Narrative Context | Camera | Map Highlight | Visual Element | Animation |
|---|---|---|---|---|---|
| 00:00–00:03 | Opening Hook | Global Zoom-in | Main Country | Title + Country | Cinematic Reveal |
| 00:03–00:06 | Location Explanation | Fly-to | L1 | Country Outline | Draw-on |
| 00:06–00:10 | Key Fact | Push-in | L5 | Number Counter | Count-up |
| 00:10–00:14 | Comparison | Split Camera | L2 | Comparison Graphic | Morph |

এটি একটি উদাহরণ মাত্র। প্রতিটি ভিডিওর প্রকৃত SRT অনুযায়ী Storyboard তৈরি করবে।

Storyboard ব্যবহারকারীকে দেখানোর জন্য। অনুমোদনের অপেক্ষায় অপ্রয়োজনীয়ভাবে কাজ থামাবে না।

## STEP 4: Research & Data Preparation

প্রয়োজন অনুযায়ী Geographic Data, Boundary, Image, Icon ও অন্যান্য Assets প্রস্তুত করবে।

যাচাই করবে:

- Country Boundaries
- Geographic Coordinates
- Route Coordinates
- City Locations
- Historical Boundaries
- Important Dates
- Population
- Area
- Economic Data

# 9. MAP HIGHLIGHT SYSTEM

## L1 — Slow Reveal

একটি প্রধান দেশ বা স্থানের জন্য।

Duration: 1.5–2.5s

Animation:

1. আশপাশের Map 0.3s-এ Dim হবে।
2. Country Outline Draw-on হবে।
3. Outline দুই দিক থেকে Draw হতে পারে।
4. Fill Fade-in হবে।
5. প্রয়োজন হলে Flag বা Country Name আসবে।
6. Country Name Pill Slide-up হবে।

## L2 — Tactical Click

একসঙ্গে একাধিক দেশ বা স্থান দেখানোর জন্য।

Duration: 2–5s

একবারে 3–8টি নাম দেখানো যেতে পারে।

Animation:

1. ছোট Glitch / RGB Split।

3. White Flash।
4. Crosshair বা Pin।
5. Country Name Pill Pop-in।

প্রতিটি দেশের জন্য আলাদা Highlight Color ব্যবহার করবে।

## L3 — Group Wash

একটি জোট বা একই রাজনৈতিক ব্লকের অনেক দেশ দেখানোর জন্য।

Duration: 0.8–1.2s

- Fill কেন্দ্র থেকে বাইরে ছড়িয়ে পড়বে।
- Stagger: 0.05s।
- একই জোট হলে একই রং।
- আলাদা দেশ বা পক্ষ হলে আলাদা রং।

## L4 — Spotlight

একটি অঞ্চলকে গুরুত্ব দেওয়ার জন্য।

Duration: 2–4s

- বাইরের অঞ্চল 50–60% Dim হবে।
- Highlight Area আসল রঙে থাকবে।

# 10. FLAG & IMAGE MASKING

Flag বা Image দিয়ে Country Area Fill করা যাবে কেবল ব্যবহারকারী স্পষ্টভাবে চাইলে।

যেমন:

"বাংলাদেশের Highlight-এর সময় দেশের ভেতরে বাংলাদেশের পতাকা দেখাও।"

তখন:

1. Country Outline থেকে SVG `clipPath` বা Mask তৈরি করবে।
2. Flag বা Image দিয়ে Area Fill করবে।
3. Image Cover Mode-এ থাকবে।
4. Opacity: 0.8–0.9।
5. প্রয়োজন অনুযায়ী Blend Mode ব্যবহার করবে।
6. Outline ও Glow উপরে থাকবে।
7. Highlight শুরু হলে 0.5s Fade-in।
8. 2–3s দৃশ্যমান থাকবে।
9. 0.5s Fade-out হয়ে সাধারণ Highlight-এ ফিরবে।

একাধিক দেশের Flag দেখাতে হলে একটির পর একটি দেখাবে।

ব্যবহারকারীর নির্দেশ ছাড়া Flag বা Image দিয়ে কোনো দেশের Area Fill করবে না।

# 13. KEYWORD & ICON SYSTEM

ভিডিওতে Subtitle থাকবে না।

শুধু গুরুত্বপূর্ণ Keyword, সংখ্যা, স্থান, ব্যক্তি বা ধারণা দেখানো যাবে।

## 13.1 Keyword Rules

- Keyword সাধারণত 2–3 শব্দের মধ্যে।
- প্রয়োজন অনুযায়ী Icon + Label + Number একসঙ্গে দেখাবে।
- Geographic Keyword হলে Map-locked হবে।
- অন্য ক্ষেত্রে Safe Screen Area ব্যবহার করবে।
- একটি সময়ে সর্বোচ্চ 1–2টি Keyword Group।
- শব্দের শুরুতে বা SRT-তে নির্ধারিত Cue-এর উপযুক্ত সময়ে Animation শুরু হবে।
- সাধারণভাবে Cue-এর Start Time-এর 0.2s আগে Visual শুরু করা যেতে পারে, যদি আগের Scene-এর সঙ্গে সংঘর্ষ না হয়।
- Cue শেষ হওয়ার 0.3–0.5s পরে Fade-out হতে পারে।
- সাধারণত 3s-এর বেশি থাকবে না।

## 13.2 Icon Animation

- প্রথম লাইন White, দ্বিতীয় লাইন Gold ব্যবহার করা যেতে পারে।
- Character বা Word-based Animation।
- অপ্রয়োজনীয় Logo Intro নয়।

দর্শক যেন প্রথম কয়েক সেকেন্ডেই বুঝতে পারেন ভিডিওটি কী নিয়ে।

## 19.2 Storytelling Flow

প্রয়োজন অনুযায়ী:

1. Hook
2. Geographic Context
3. Main Explanation
4. Supporting Facts
5. Comparison / Conflict
6. Important Reveal
7. Conclusion

সব ভিডিওতে একই Story Structure বাধ্যতামূলক নয়।

SRT-এর Narrative Flow অনুযায়ী Scene তৈরি করবে।

## 19.3 Ending

শেষ 4 সেকেন্ডে:

- Camera ধীরে Pull-back করতে পারে।
- প্রয়োজন হলে Opening Shot-এ ফিরে যাবে।
- Final Message বা Question দেখাবে।
- Gold Keyword ব্যবহার করা যাবে।
- প্রয়োজন অনুযায়ী CTA।
- 0.4s Fade-out।

Storytelling Video হলে Seamless Loop তৈরি করার চেষ্টা করবে।

# 20. AUDIO & SOUND DESIGN

## 20.1 Voiceover থাকলে

- Voiceover-এর ওপর Sound Effect চাপ সৃষ্টি করবে না।
- Sound Effect প্রয়োজন অনুযায়ী Voiceover-এর তুলনায় কম রাখবে।

## 20.2 Voiceover না থাকলে

- SRT-ই হবে Timeline।
- প্রয়োজন অনুযায়ী Sound Effects ব্যবহার করা যাবে।

# 22. ADVANCED DATA ACCURACY & FACT CHECKING

Map Animation শুধু সুন্দর হলেই হবে না। তথ্যও নির্ভুল হতে হবে।

- Data-এর Unit পরিষ্কার রাখবে।

- Historical Event-এ নিশ্চিত তথ্য ও বিতর্কিত ব্যাখ্যার পার্থক্য বজায় রাখবে।

- অপ্রয়োজনীয় Filter এড়িয়ে চলবে।

- Render Concurrency প্রয়োজন অনুযায়ী নির্ধারণ করবে।

## 23.4 Timing Calculation

SRT Timestamp থেকে Frame বের করবে।

Formula:

`frame = timeInSeconds × fps`

30 FPS-এ:

- 1 Second = 30 Frames
- 0.2 Second = 6 Frames
- 0.5 Second = 15 Frames
- 1 Second = 30 Frames

SRT Timestamp থেকে Frame Conversion করার সময় Rounding ও Cue Boundary সঠিকভাবে পরিচালনা করবে।

## 23.5 Asset Loading

- Final Render-এর আগে প্রয়োজনীয় Image ও Tile Load নিশ্চিত করবে।
- `delayRender` ও `continueRender` প্রয়োজন অনুযায়ী ব্যবহার করবে।
- Loading Failure হলে Error Handling করবে।
- Remotion-এর `Img` ব্যবহার করবে।
- Tile Loading-এর জন্য পর্যাপ্ত Timeout রাখবে।

## 25.3 Tile Loading Error

Frame Missing, Black Tile বা `delayRender` Timeout হলে প্রয়োজনে:

```bash
npm run render -- --concurrency=1 --timeout=120000
```

কারণ:

- `--concurrency=1` একবারে একটি Frame Process করে, ফলে Tile Download-এর ওপর চাপ কমে; তবে Render ধীর হতে পারে।
- `--timeout=120000` প্রতিটি Frame-এর জন্য সর্বোচ্চ 120 সেকেন্ড অপেক্ষা করার সুযোগ দেয়।

## 25.4 Render Inspection

Render-এর পর:

- Zoom-out Section পরীক্ষা করবে।
- Camera Transition পরীক্ষা করবে।
- Missing Tile পরীক্ষা করবে।
- গুরুত্বপূর্ণ Frame Scrub করবে।
- প্রয়োজন হলে শুধু সমস্যাযুক্ত Frame পুনরায় Render করবে।

উদাহরণ:

```bash
npx remotion render --frames=100-200
```

`render:local` ব্যবহার করবে না, যদি সেটি নিম্নমানের বা Blur Fallback তৈরি করে।

# 29. FINAL EXECUTION PRINCIPLES

সবশেষে নিচের বিষয়গুলো সর্বোচ্চ গুরুত্ব দিয়ে অনুসরণ করবে।

**1. SRT is Mandatory**

SRT ছাড়া এই Workflow শুরু করবে না। SRT-ই হবে ভিডিওর Content ও Timeline-এর প্রধান ভিত্তি।

**2. Voiceover is Optional**

Voiceover না থাকলেও সম্পূর্ণ ভিডিও তৈরি করতে পারবে। কোনো Narration নিজে থেকে যোগ করবে না।

**3. Every Video is Independent**

প্রতিটি ভিডিও হবে একটি স্বতন্ত্র Remotion Project। Reusable Engine বা পূর্ববর্তী Project-এর ওপর নির্ভর করবে না।

**4. Visual Storytelling First**

প্রতিটি তথ্যকে যথাসম্ভব Geographic Visual, Map Animation ও Motion Graphics দিয়ে বোঝাবে।

**5. Geographic Accuracy**

Map, Boundary, Route, Location ও Data-এর নির্ভুলতা বজায় রাখবে।

**6. Creative Freedom**

প্রতিটি নতুন ভিডিওতে প্রয়োজন অনুযায়ী নতুন Animation, Camera Technique, Visual Effect ও Storytelling Method তৈরি করবে।

**7. No Unnecessary Questions**

Optional Asset না থাকলে প্রশ্ন করবে না। নিজে সিদ্ধান্ত নিয়ে কাজ করবে।

**8. No Fake Information**

কোনো সংখ্যা, তারিখ, Location বা Historical Event বানিয়ে দেখাবে না।

**9. Quality over Effects**

অতিরিক্ত Animation নয়; সঠিক Visual Communication-ই প্রধান লক্ষ্য।

**10. Complete Delivery**

শুধু কোড নয়, সম্পূর্ণ Project, প্রয়োজনীয় Assets, Commands এবং Render Instructions দেবে।
